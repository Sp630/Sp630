## Start here

**[bgslr-static](https://github.com/Sp630/bgslr-static)**: Real-time recognizer for the Bulgarian one-handed dactylic (fingerspelling) alphabet. MediaPipe hand landmarks → custom CNN trained on a 12,000-image dataset I collected → letters → words → text-to-speech.

**[bgslr-video](https://github.com/Sp630/bgslr-video)** *(prototype)*: Version 2. Talking with Deaf signers about v1 made it clear that static recognition wasn't enough, since many signs involve motion. This version works on video, combining 33 body-pose landmarks with per-hand tracking, and currently recognizes a small set of signs.

**[CIFAR-10 from scratch](https://github.com/Sp630/CIFAR-10-94-test-accuracy-tensorflow-within-80-epochs-from-scratch)**: VGG-style network in TensorFlow, trained from scratch to 94%+ test accuracy within 80 epochs.
